Principais Comandos do GIT

O Git é um sistema de controle de versão distribuído, usado para acompanhar alterações em arquivos e colaborar em projetos de software.

1. Inicialização e clonagem

git init
Inicializa um repositório Git em uma pasta local. 
git init
git clone
Clona um repositório remoto para a máquina local. 
git clone https://github.com/usuario/repositorio.git

2. Verificando o estado do projeto

git status
Mostra arquivos modificados, adicionados ou prontos para commit. 
git status
git log
Exibe o histórico de commits do projeto. 
git log

3. Adicionando e salvando alterações

git add
Adiciona arquivos à área de staging. 
git add nome-do-arquivo.txt
git add .
git commit
Salva as alterações no histórico do repositório. 
git commit -m "Descrição da alteração"

4. Trabalhando com branches

git branch
Lista ou cria branches. 
git branch
git branch nome-da-branch
git checkout
Alterna entre branches ou restaura arquivos. 
git checkout nome-da-branch
git switch
Alterna de forma mais clara entre branches. 
git switch nome-da-branch
git merge
Junta alterações de uma branch em outra. 
git merge nome-da-branch

5. Sincronizando com repositórios remotos

git remote
Visualiza ou configura repositórios remotos. 
git remote -v
git remote add origin https://github.com/usuario/repositorio.git
git pull
Atualiza o repositório local com as alterações do remoto. 
git pull origin main
git push
Envia as alterações locais para o repositório remoto. 
git push origin main

6. Desfazendo alterações

git restore
Restaura arquivos para o estado de um commit anterior. 
git restore nome-do-arquivo.txt
git reset
Remove alterações do staging ou reverte commits. 
git reset HEAD nome-do-arquivo.txt
git reset --hard HEAD~1

7. Trabalhando com versões e tags

git tag
Cria marcações para versões importantes do projeto. 
git tag v1.0.0
git diff
Mostra as diferenças entre versões ou alterações pendentes. 
git diff

8. Guardando alterações temporariamente

git stash
Guarda alterações temporárias sem fazer commit. 
git stash
git stash list
git stash apply

Resumo

  • git init: inicia um repositório local.
  • git clone: copia um projeto de um repositório remoto.
  • git add: prepara arquivos para commit.
  • git commit: grava alterações no histórico.
  • git status: verifica o estado do projeto.
  • git branch: gerencia branches.
  • git merge: junta alterações entre branches.
  • git pull: atualiza com o remoto.
  • git push: envia alterações para o remoto.
  • git stash: salva alterações temporárias.
