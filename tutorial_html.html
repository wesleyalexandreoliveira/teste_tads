Tutorial básico de HTML

HTML (HyperText Markup Language) é a linguagem usada para estruturar o conteúdo de páginas web. Com ele, organizamos textos, imagens, links, formulários e muito mais.

1. Estrutura básica da página

Todo documento HTML começa com algumas tags importantes:

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <title>Meu site</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
  </body>
</html>
  • <!DOCTYPE html>: informa ao navegador que o documento é HTML5.
  • <html>: envolve todo o conteúdo da página.
  • <head>: contém configurações e metadados.
  • <body>: contém o conteúdo visível da página.

2. Títulos e parágrafos

Usamos títulos para organizar o conteúdo:

<h1>Título principal</h1>
<h2>Subtítulo</h2>
<h3>Seção menor</h3>

<p>Este é um parágrafo de texto.</p>

3. Formatação de texto

Existem tags para destacar partes do texto:

<strong>Texto importante</strong>
<em>Texto em itálico</em>
<u>Texto sublinhado</u>
<mark>Texto marcado</mark>

Texto importante e texto em itálico. Também pode ter texto sublinhado e texto marcado.

4. Listas

Podemos criar listas ordenadas e não ordenadas:

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>

<ol>
  <li>Primeiro</li>
  <li>Segundo</li>
</ol>
  • Item 1
  • Item 2
  1. Primeiro
  2. Segundo

5. Links e imagens

Para criar links e inserir imagens:

<a href="https://www.google.com" target="_blank">Visite o Google</a>

<img src="https://via.placeholder.com/300" alt="Imagem de exemplo">
Visite o Google

6. Tabelas

As tabelas ajudam a organizar dados em linhas e colunas:

<table>
  <tr>
    <th>Nome</th>
    <th>Idade</th>
  </tr>
  <tr>
    <td>Ana</td>
    <td>22</td>
  </tr>
</table>

7. Formulários

Com o elemento <form>, criamos campos para entrada de dados:

<form>
  <label for="nome">Nome:</label>
  <input type="text" id="nome" name="nome">
  <button type="submit">Enviar</button>
</form>

8. Tags semânticas

Tags semânticas deixam o HTML mais organizado e acessível:

<header>Cabeçalho</header>
<nav>Menu de navegação</nav>
<main>Conteúdo principal</main>
<section>Seção</section>
<article>Artigo</article>
<footer>Rodapé</footer>
  • <header>: área do cabeçalho
  • <nav>: navegação
  • <main>: conteúdo principal
  • <section>: seção da página
  • <footer>: rodapé
